# CLI

```text
anyl [OPTIONS] [FILE/DIR/GLOB]...
```

各ファイルを整形して結果を出力します。引数がなければ標準入力を読みます。引数に指定できるものは[ファイル](#files)を参照してください。

## ファイル \{#files}

各引数には、Prettier や oxfmt と同じくファイル、ディレクトリ、グロブパターンを指定できます。

| 引数                 | 意味                                           |
| ------------------ | -------------------------------------------- |
| `index.html`       | そのファイル                                       |
| `src`、`.`          | ディレクトリ内の対応ファイルすべて（再帰的）                       |
| `"src/**/*.vue"`   | グロブに一致する対応ファイル。`*` はディレクトリをまたがず、`**` はまたぎます。 |
| `"!src/legacy/**"` | 一致するファイルをほかの引数の結果から除外                        |

グロブは `anyl` 自身が展開するので、どのシェルでも、package.json の scripts でも動きます。シェルに先に展開されないよう、クォートしてください。

ディレクトリとグロブでは、隠しファイル・隠しディレクトリ、`node_modules`、`.gitignore` または `.anylignore` に書かれたファイルを飛ばします。`.anylignore` は gitignore 形式で、`.prettierignore` と同じく探索する各ディレクトリで読みます。直接指定したファイルは常に整形します。

どのファイルにも一致しない引数はエラー（終了コード `2`）です。`--no-error-on-unmatched-pattern` を指定するとエラーにしません。

## オプション

| オプション                             | 説明                                                                                                                |
| --------------------------------- | ----------------------------------------------------------------------------------------------------------------- |
| `-w`, `--write`                   | ファイルをその場で上書きします。`--check` とは併用できません。                                                                              |
| `-c`, `--check`                   | 変更が必要なファイルのパスを出力し、1 つでもあれば終了コード 1 で終了します。                                                                         |
| `-p`, `--profile <PROFILE>`       | 組み込みプロファイル名（`html`、`vue`）またはプロファイル YAML ファイルのパス。既定は各ファイルの言語に対応する組み込みプロファイルです。                                     |
| `--class-order <CLASS_ORDER>`     | 静的な `class` 属性のクラスを並べ替えます。組み込みのクラス順の名前（`tailwind`、`bootstrap`）またはクラス順 YAML ファイルのパス。プロファイルの `classOrder` より優先されます。 |
| `-l`, `--language <LANGUAGE>`     | 標準入力の言語: `html`（既定）、`vue`、`css`、`scss`、`sass`、`less`                                                              |
| `--no-error-on-unmatched-pattern` | どのファイルにも一致しない引数があってもエラーにしない                                                                                       |
| `-h`, `--help`                    | ヘルプを表示します。                                                                                                        |
| `-V`, `--version`                 | バージョンを表示します。                                                                                                      |

## 言語

ファイルの言語は拡張子から判定します。

| 拡張子                            | 言語      | 既定のプロファイル                     |
| ------------------------------ | ------- | ----------------------------- |
| `.html`、`.htm`                 | `html`  | `html`                        |
| `.vue`                         | `vue`   | `vue`                         |
| `.css`、`.scss`、`.sass`、`.less` | スタイルシート | `html`（その `stylesheet` セクション） |

それ以外の拡張子は未対応として報告します。

## 終了コード

| コード | 意味                                                                                  |
| --- | ----------------------------------------------------------------------------------- |
| `0` | 成功。`--check` の場合は、変更が必要なファイルがない。                                                    |
| `1` | `--check` の場合に、変更が必要なファイルが 1 つ以上ある。                                                 |
| `2` | エラー: ファイルを読めない、未対応のファイル形式、不正なプロファイル、不正な入力、未知の `annealer-*` ディレクティブ、どのファイルにも一致しない引数。 |

複数のファイルを指定した場合は、すべてを処理してエラーを個別に報告し、1 つでも失敗があれば `2` で終了します。

## 例

```bash
anyl src/App.vue                          # 結果を出力
anyl --write "src/**/*.vue"               # その場で上書き
anyl --write . "!src/legacy/**"          # ディレクトリからパターンを除外
anyl --check index.html                   # CI で使う
anyl --profile my-profile.yaml page.html  # 独自プロファイル
anyl --class-order tailwind "src/**/*.vue" # Tailwind のクラスを並べ替える
cat App.vue | anyl --language vue         # 標準入力
```
