    #API 概要

    annealer は 1 つの Rust コアを、いくつかの方法で呼び出せます。

    入口用途リファレンス
    anylコマンドラインや CI でのファイル整形CLI
    annealer（npm）WebAssembly 経由で Node.js、ブラウザー、バンドラーから利用JavaScript API
    プロファイル YAML属性順、レイアウト、スタイルシートのオプションのカスタマイズプロファイルリファレンス

    Rust の関数 annealer::format(input, &Config) は純粋関数で、ファイル I/O を行いません。そのため同じコアが CLI でも WebAssembly でも動きます。
